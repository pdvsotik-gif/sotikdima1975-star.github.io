# СайтСотика — Официальный сайт

Этот репозиторий содержит полный исходный код официального сайта Сотика — стримера, увлеченного автосимуляторами. Сайт построен на статических HTML, CSS и JavaScript файлах и организован с использованием современных веб-принципов.

## Общая структура проекта

Проект представляет собой статический веб-сайт, размещённый на GitHub Pages. Основное содержимое находится в папке `pages/main/`, откуда пользователь перенаправляется через `index.html` в корне репозитория.

## Полное техническое описание всех файлов, секций и элементов

### Корневые файлы

- **Назначение:** Определяет файлы и директории, которые должны игнорироваться системой контроля версий Git.

## Подробное техническое описание функционала кнопки "Игры"

Кнопка "Игры" является центральным элементом навигации на сайте СотикаСтрим, обеспечивающим доступ к многоуровневому меню выбора игровых серий и конкретных игр. Её функционал реализован через комбинацию HTML, CSS и JavaScript, что позволяет создавать динамическое, отзывчивое и визуально привлекательное подменю без перезагрузки страницы.

### 1. Местоположение и структура кнопки в HTML

Кнопка "Игры" определена в файле `pages/main/index.html` внутри основного навигационного меню:

```html
<a href="#" class="nav-link" data-page="games">Игры</a>
```

Разберём каждый атрибут:

- **`<a>`** — тег ссылки, используемый для создания интерактивного элемента. Хотя это не ведёт на другую страницу, он семантически корректен для навигационных элементов и обеспечивает встроенные поведения (например, фокус, доступность).
- **`href="#"`** — указывает, что ссылка ведёт на текущую страницу. Это предотвращает переход по умолчанию, но позволяет кнопке быть активной и кликабельной. В будущем это может быть заменено на `href="games.html"` для улучшения SEO, если будет создана отдельная страница.
- **`class="nav-link"`** — присваивает кнопке общие стили для всех пунктов меню, определённые в `css/styles.css`. Эти стили включают:
  - Закруглённые края (`border-radius: 999px`)
  - Градиентный фон с эффектом стекла
  - Тени (`box-shadow`) для объёма
  - Плавные переходы (`transition`) для hover-эффектов
  - Верхнюю панель с неоновым градиентом
  - Нижний золотой акцент
- **`data-page="games"`** — пользовательский data-атрибут, используемый JavaScript для идентификации этой конкретной кнопки. Это ключевой элемент, так как именно по нему скрипт находит и привязывает обработчик события. Использование `data-*` атрибутов — это стандартная практика для хранения информации, специфичной для приложения, не влияющей на визуальное отображение.

### 2. Стилизация кнопки в CSS

Стили кнопки определены в `css/styles.css` в секции "МЕНЮ". Основные правила:

- **`.nav-link`** — базовые стили, применяемые ко всем кнопкам меню, включая "Игры".
- **`.nav-link:hover`** — эффект при наведении:
  - Усиление градиента фона
  - Смена цвета текста на белый (`#f5f6ff`)
  - Увеличение интерлиньяжа (`letter-spacing: 0.18em`)
  - Увеличение тени (`box-shadow`)
  - Подъём кнопки на 1px (`transform: translateY(-1px)`)
  - Активация анимации свечения (`animation: buttonHoverGlow 1.6s ease-in-out infinite`)
- **`.nav-link:active`** — эффект при клике:
  - Временное уменьшение размера (`transform: scale(0.96)`)
  - Создаёт тактильное ощущение нажатия
- **`.nav-link::before`** — внутренний глянец, создающий эффект блика сверху
- **`.nav-link::after`** — нижняя анимированная линия, которая плавно появляется при наведении

Важно, что кнопка "Игры" не имеет уникального класса, поэтому её визуальное поведение полностью определяется общими стилями `.nav-link`. Это обеспечивает единообразие дизайна.

### 3. Логика работы в JavaScript

Основной функционал кнопки реализован в файле `js/script.js`. Разберём его по шагам.

#### a) Поиск элемента и привязка обработчика

```javascript
header.querySelector("[data-page='games']").addEventListener("click", function (e) {
    e.preventDefault();
    mainNav.style.display = "none";
    createGamesNav();
    attachEventListeners();
});
```

- **`header.querySelector("[data-page='games']")`** — находит кнопку по её data-атрибуту. Использование селектора по `data-*` атрибуту более надёжно, чем по классу или тексту, так как он не зависит от визуального оформления.
- **`.addEventListener("click", ...)`** — привязывает обработчик события клика. Это означает, что при каждом клике будет выполнена указанная функция.
- **`e.preventDefault()`** — отменяет стандартное поведение ссылки (переход к якорю `#`). Это необходимо, так как кнопка не должна прокручивать страницу вверх.

#### b) Действия при клике

После отмены стандартного поведения выполняются три действия:

1. **`mainNav.style.display = "none";`** — скрывает основное меню (`#main-nav`). Это визуально очищает пространство для нового подменю. Важно, что меню не удаляется, а только скрывается, что позволяет легко вернуть его позже.

2. **`createGamesNav();`** — вызывает функцию, которая создаёт новое меню выбора игровых серий. Эта функция определена ниже в скрипте.

3. **`attachEventListeners();`** — повторно привязывает обработчики событий к новым элементам. Это необходимо, потому что новые кнопки созданы динамически и изначально не имеют обработчиков.

### 4. Функция `createGamesNav()`


Эта функция создаёт первое подменю — выбор игровой серии. Полный код:

```javascript
function createGamesNav() {
    cleanup();
    const gamesNav = document.createElement("nav");
    gamesNav.id = "games-nav";
    gamesNav.innerHTML = `
        <a href="#" class="nav-link back-link" data-back>← Назад</a>
        <a href="#" class="nav-link game-series" data-series="forza">Forza Motorsport</a>
        <a href="#" class="nav-link game-series" data-series="ac">Assetto Corsa</a>
        <a href="#" class="nav-link game-series" data-series="pc">Project Cars</a>
    `;
    styleNav(gamesNav);
    header.appendChild(gamesNav);
    logo.textContent = "Игры • СайтСотика";
}
```

Разберём по шагам:

- **`cleanup();`** — вызывает функцию очистки, которая удаляет все дополнительные `<nav>` элементы, кроме `#main-nav`. Это предотвращает накопление старых меню и возможные конфликты.
- **`document.createElement("nav")`** — создаёт новый элемент `<nav>`, который будет контейнером для подменю.
- **`gamesNav.id = "games-nav"`** — присваивает контейнеру уникальный идентификатор. Это позволяет легко находить и управлять этим меню позже.
- **`gamesNav.innerHTML = ...`** — задаёт содержимое меню в виде строки HTML. В нём три элемента:
  - **Кнопка "Назад"** — с классом `back-link` и атрибутом `data-back`. Используется для возврата к основному меню.
  - **Три кнопки выбора серии** — каждая с классом `game-series` и уникальным `data-series` атрибутом (`forza`, `ac`, `pc`). Эти атрибуты используются для определения, какое подменю открыть.
- **`styleNav(gamesNav);`** — вызывает вспомогательную функцию, которая применяет единые стили к новому меню (flex-расположение, отступы и т.д.).
- **`header.appendChild(gamesNav);`** — добавляет новое меню в хедер, делая его видимым.
- **`logo.textContent = "Игры • СайтСотика";`** — меняет текст логотипа, чтобы визуально указать пользователю, что он находится в разделе "Игры".

### 5. Функции создания подменю для конкретных серий

После выбора серии (например, "Forza Motorsport") вызываются соответствующие функции: `createForzaNav()`, `createAcNav()`, `createPcNav()`.

Пример для Forza:

```javascript
function createForzaNav() {
    cleanup();
    const forzaNav = document.createElement("nav");
    forzaNav.id = "forza-nav";
    forzaNav.innerHTML = `
        <a href="#" class="nav-link back-link" data-back>← Назад к сериям</a>
        <a href="games/forza/motorsport7.html" class="nav-link">Forza Motorsport 7</a>
        <a href="games/forza/motorsport8.html" class="nav-link">Forza Motorsport 8</a>
    `;
    styleNav(forzaNav);
    header.appendChild(forzaNav);
    logo.textContent = "Forza Motorsport • СайтСотика";
}
```

Эти функции работают аналогично `createGamesNav()`, но:
- Ссылаются на реальные HTML-страницы (например, `motorsport7.html`)
- Меняют текст логотипа на название выбранной серии
- Кнопка "Назад" теперь возвращает к выбору серий, а не к основному меню

### 6. Обработка навигации и возврата

Функция `attachEventListeners()` обеспечивает работоспособность всех динамически созданных кнопок:

```javascript
function attachEventListeners() {
    // Кнопка "Назад"
    header.querySelectorAll("[data-back]").forEach(button => {
        button.addEventListener("click", function (e) {
            e.preventDefault();
            const parentId = this.closest("nav").id;

            cleanup();

            if ([
