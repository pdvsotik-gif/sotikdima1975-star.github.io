## 📐 Структура CSS файлов

### 1. **header.css**
Стили для шапки сайта с адаптивной логикой:
- Мобильная кнопка меню (☰) появляется при ≤ 640px
- Размер логотипа и кнопок адаптируется
- Поддержка альбомной ориентации (landscape)

### 2. **welcome.css**
Основной контент и приветственная секция:
- Гибко меняющиеся размеры шрифтов
- Переход с горизонтального макета (30%-70%) на вертикальный (100%)
- Адаптивные паддинги и отступы

### 3. **responsive.css** (НОВЫЙ)
Универсальные адаптивные стили:
- Мобильное меню (меню-гамбургер)
- Видео-секция
- Приветственные тексты
- Touch-friendly экраны
- Поддержка Safe Area (notch на iPhone)

## 🔧 JavaScript для мобильности

## 📋 HTML Meta-теги

```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Официальный сайт стримера Дмитрия Переднего">
<meta name="theme-color" content="#6a11cb">
```

- **viewport** — масштабирование для мобильных устройств
- **theme-color** — цвет строки браузера на Android

## 🎯 Ориентация (Portrait & Landscape)

### Портретная (Portrait)
- По умолчанию используется вертикальный макет
- Макет 30%-70% (фото-контент) переходит в 100%-100% при ≤ 960px

### Альбомная (Landscape)
- При max-height: 500px — компактный макет (меньше паддинги)
- При min-height: 500px и max-height: 800px — нормальный макет
- При min-height: 800px — комфортный макет для планшетов в горизонтали

## 🚀 Практики и лучшие подходы

### DO ✅
- Использовать `em` и `rem` вместо `px` для размеров шрифтов
- Добавлять `box-sizing: border-box;` ко всем элементам
- Использовать медиа-запросы для трансформации макета
- Тестировать на реальных устройствах
- Использовать `max-width` для контейнеров
- Отступы: padding > margin

### DON'T ❌
- Не использовать жесткие размеры (width: 960px)
- Не забывать про viewport meta-tag
- Не игнорировать tiny экраны (< 320px)
- Не использовать старые стили без медиа-запросов
- Не забывать про Touch-friendly размеры кнопок (min 44x44px)

## 🎓 Примеры медиа-запросов

### Только мобайл
```css
@media (max-width: 640px) {
    /* Стили только для мобильных устройств */
}
```

### Только планшет
```css
@media (min-width: 641px) and (max-width: 1024px) {
    /* Стили для планшетов */
}
```

### Только десктоп
```css
@media (min-width: 1200px) {
    /* Стили для десктопов */
}
```

### С учетом ориентации
```css
@media (orientation: portrait) and (max-width: 768px) {
    /* Портретные мобайлы и планшеты */
}

@media (orientation: landscape) {
    /* Альбомные устройства */
}
```

### Сенсорные устройства
```css
@media (hover: none) and (pointer: coarse) {
    /* Стили для устройств без mouse (сенсор) */
    button {
        min-height: 48px; /* Удобнее для пальца */
    }
}
```

## 🐛 Частые проблемы и решения

### Проблема: Меню не скрывается на мобайле
**Решение:** Проверьте, что в `header.js` точка срабатывания установлена на `640px`

### Проблема: Текст слишком маленький на мобайле
**Решение:** Используйте медиа-запросы для увеличения `font-size` на мобайлах

### Проблема: Видео не подгоняется под экран
**Решение:** Используйте `padding-bottom` с процентами для сохранения пропорции 16:9

### Проблема: Кнопки слишком маленькие для пальца
**Решение:** Установите минимальный размер кнопки в 44x44px для мобайлов
