🔄 Тестирование ориентации

✅ Что проверить:

  1. Портретная (Portrait): Меню должно переходить на мобильное меню при ≤ 640px
  2. Альбомная (Landscape): На маленьких экранах должна быть компактная версия
  3. Текст: Читаем ли на всех ориентациях без горизонтальной прокрутки
  4. Кнопки: Удобны ли для нажатия пальцем (размер не менее 44x44px)
  5. Видео: Видео-плеер должен масштабироваться адаптивно

🧪 Инструкция по тестированию

Способ 1: DevTools браузера

  1. Откройте сайт в браузере
  2. Нажмите F12 для открытия DevTools
  3. Нажмите иконку мобильного устройства (Ctrl+Shift+M)
  4. Выберите нужное устройство из списка
  5. Протестируйте все функции

Способ 2: Кнопки на этой странице

  1. Используйте кнопки выше, чтобы имитировать размеры устройств
  2. Откройте в соседней вкладке основной сайт
  3. Измените размер окна браузера на нужный размер
  4. Проверьте все компоненты

Способ 3: Реальное устройство

  1. Откройте сайт на смартфоне или планшете
  2. Поворачивайте устройство между портретом и альбомом
  3. Проверьте удобство использования
  4. Убедитесь, что нет горизонтальной прокрутки
